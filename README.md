# AI Student Attendance Risk Management System v2.0

Advanced DBMS + Machine Learning version. It supports student entry, CSV bulk import, automatic attendance calculation, AI risk prediction, search/filter/delete, and prediction history.

## First-time upgrade
Run `database/02_advanced_features.sql` once in SQL*Plus connected to FREEPDB1 as SYSTEM.

## Run backend
cd backend
python app.py

## Dashboard
Open `frontend/index.html` with VS Code Live Server.

CSV format is provided in `dataset/sample_students.csv`.
